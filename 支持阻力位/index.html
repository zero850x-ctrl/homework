四類（這篇只開這四類，其餘九類在第二篇）

支持 / 阻力唔係得一種畫法。以下四類由淺入深，第 4 類係進階，初學者最易走火入魔。

01

橫線

市場曾經尊重過的價格，通常是趨勢轉折位。第一個轉折已可假設它是潛在支持 / 阻力， 但仍要用價格到達時的反應去確認。有人因此用前頂前底做目標或止蝕。
同一價位兩次轉勢後，成為強力位，因為參與者已經尊重它兩次； 第三次觸及就可以假設它仍是支持 / 阻力。

✓ 兩次轉勢 = 強力位 · 第三次觸及可假設有效
02

直線趨勢線

上升趨勢線是支持，下降趨勢線是阻力。來源是口頭禪： 「等它回一回我就買」「等它升回一點我就止蝕」。
趨勢本身來自羊群同確認性偏差（confirmation bias） — 大家都睇同一條線，所以條線先會應驗。

✓ 上升線 = 支持 · 下降線 = 阻力
03

移動平均線

10、50、250 天等，實務上常成為支持 / 阻力。
個人經驗：用均線看支持有效，看阻力一般。
補註：恆指可用 8、13、34 線（分鐘、小時、天通用）；其他市場可能不同。

✓ 10 / 50 / 250 天 · 睇支持準過睇阻力
04

自然支持 / 阻力，即黃金比率

常見 50% 同 61.8%。一段升浪回調到升幅的 50% 或 61.8%， 可以預期那裡有支持。
這是進階，也是初學者最容易走火入魔的一類，詳情留待後面。

⚠ 進階 · 唔好迷信比率

確認真假：潛在位 + 價格反應

確認真假的方法很多，這篇先講最常用的一種：在潛在位觀察價格同成交量的反應， 尤其是陰陽燭反轉形態。出現以下形態，先把「可能的線」升級成「真支持」。

01

破腳穿頭（bullish engulfing）

陽燭成支吞晒上一支陰燭 — 潛在支持上出現，即係買方一次過收復失地，轉勢訊號最強烈。

✓ 最強烈嘅底部反轉之一
02

曙光初現（piercing）

陽燭低開、收市收返上支陰燭實體一半以上 — 跌勢中見到，代表沽壓開始頂唔住。

✓ 收返陰燭實體一半以上先算數
03

平底（tweezer bottoms）

兩支（或多支）燭低位幾乎一樣 — 同一價位多次跌唔穿，橫線支持嘅即場版。

✓ 低點齊頭 = 跌唔穿嘅證據
04

早晨之星（morning star）

大陰燭 → 細星燭 → 大陽燭，三支組合 — 跌、猶豫、升，情緒轉向走晒出嚟。

✓ 三支組合 · 中間係猶豫星

支持變阻力

向下突破支撐後，原來托住價格嘅地板會反轉變成天花板 — 之後升返上嚟會喺呢個位遇到阻力。 （原筆記此段未及抄全，待第二篇補上。）

總結

一句話記住：第一次轉折只係潛在位；兩次轉勢先係強力位；有陰陽燭反轉確認先係真支持。

①

橫線 — 市場尊重過嘅價；兩次轉勢成強力位，第三次觸及可假設有效。

②

趨勢線 — 上升支持、下降阻力；本質係羊群 + 確認性偏差。

③

均線 — 10 / 50 / 250 天；睇支持有效，睇阻力一般。

④

黃金比率 — 50% / 61.8% 回調預期支持；進階，唔好走火入魔。

⚠

最大陷阱 — 見線就當真，唔等價格反應同燭形確認。
